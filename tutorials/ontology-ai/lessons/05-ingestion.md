# 第 05 课　数据导入与来源

目标：生成可交换的图数据，观察身份、单位、时间与来源摘要。对应书籍第 07 章。

## 操作

```console
python -m ontology_lab ingest --workdir .runs/ingestion-lesson
```

目录中产生 `dataset.trig` 与 `ingestion-manifest.json`。报告中的 `p102_temperature_c` 应为 `72.0`。对照华氏度转换公式：`(161.6 - 32) × 5 / 9 = 72`。

用编辑器查看 TriG 文件，定位两个命名图、P-102 的独立观测和 `xsd:decimal` 值。三元组输出顺序可以改变，不影响图结构。

## 解释

导入器用租户与业务编号构造身份，拒绝重复设备键或重复观测键；观测必须关联到同租户的设备。未知单位、无时区时间以及非有限数值不能静默接受。

清单保存源 CSV 文件的 SHA-256。它表示文件字节版本，不是 RDF 语义规范化摘要；调整 CSV 行顺序或换行，也可能改变文件哈希。需要判断图是否等价时，应另用图同构或适当规范化方法。

数据中保留观测发生时间和设备快照时间。生产环境通常还需要导入时间、源系统版本、处理活动和错误隔离区。本例是自定义 CSV 映射，并未实现 R2RML 或完整 PROV 来源管理。

## 常见失败

复制一行设备后得到 `DUPLICATE_KEY` 是预期行为。时间字符串没有 `Z` 或时区偏移会被拒绝，程序不会猜测服务器本地时区。输入新枚举前应先定义映射规则。

## 练习

在源文件副本中制造重复键、未知单位和无时区时间，分别说明应修复来源、修改映射还是进入人工处理。可以通过 `build_dataset(assets_path=..., observations_path=...)` 传入副本；不要改坏后续课程共用的数据。
